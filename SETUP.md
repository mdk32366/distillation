# Setup (Windows)
1. Need Python 3.10+ on PATH (`python --version`).
2. Double-click `setup.bat` (or run it in a terminal from `C:\Projects\distillation`). It creates `.venv`, installs `requirements.txt`, and registers a Jupyter kernel named **Python (distillation)**.
3. Open the folder in VS Code, open `notebooks\01-toy-distillation.ipynb`, choose kernel **Python (distillation)** (top right), then Run All.
